# 报价系统 (Quotation System)

## 📁 文件结构

### 🚀 核心文件
- **`main.m`** - 主入口脚本，设置参数并调用报价计算
- **`quotation_main.m`** - 主调度函数，协调整个报价计算流程
- **`calc_profit.m`** - 成本与利润计算函数，核心定价逻辑

### 🧮 计算模块
- **`calc_freight.m`** - 运费计算模块
- **`get_insurance.m`** - 保险费计算模块
- **`get_creditcost.m`** - 信用成本计算模块
- **`get_clearance.m`** - 清关费用计算模块
- **`get_payment_risk.m`** - 付款风险系数计算模块
- **`adjust_loandays.m`** - 贷款天数调整模块
- **`poly_func.m`** - 数量折扣函数模块

### 📊 报价脚本
- **`Quote20250701.m`** - 报价脚本（.m格式）
- **`Quote20250701.mlx`** - 报价脚本（Live Script格式）

### 📚 文档
- **`价格计算逻辑说明.md`** - 详细的价格计算逻辑和公式说明

## 🔧 使用方法

### 快速开始
1. 在MATLAB中打开 `main.m`
2. 根据需要调整参数设置
3. 运行脚本即可获得报价结果

### 参数配置
主要参数在 `main.m` 中设置：
- `param.er` - 汇率
- `param.days` - 付款天数
- `param.Pay` - 付款条件
- `param.Incoterms` - 贸易术语
- `param.CommissionRate` - 委托费比例
- `param.profMargin0` - 利润率

## 📈 计算逻辑

### 核心定价公式
```
销售价格 = 不含税成本 + 利润 + 总费用 + 委托费
```

### 利润计算
```
利润 = 销售价格 × 利润率
```

### 各项费用
- **保险费**：基于贸易术语和销售价格
- **利息费用**：基于贷款金额和天数
- **杂项费用**：包含信用成本和清关费
- **委托费**：基于销售价格的比例

## 🎯 功能特点

- ✅ **基于售价的利润计算**：确保利润率始终是售价的固定比例
- ✅ **完整的费用体系**：考虑所有国际贸易相关费用
- ✅ **灵活的付款条件**：支持TT、DP、LC、DA等多种付款方式
- ✅ **风险调整机制**：根据付款条件自动调整风险系数
- ✅ **数量折扣**：支持基于订单规模的折扣计算
- ✅ **委托费支持**：可配置的委托费比例

## 📋 输出结果

系统输出包含以下信息：
- 产品信息（编号、数量）
- 付款条件（方式、天数）
- 价格信息（总价、单价）
- 利润信息（利润、利润率）
- 成本信息（不含税成本）
- 费用明细（总费用、运费、保险费、利息、杂费、委托费）
