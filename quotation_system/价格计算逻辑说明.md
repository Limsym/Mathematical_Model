# 价格计算逻辑详细说明

## 📊 概述
本系统用于计算国际贸易中的产品定价，考虑了成本、利润、各项费用和委托费等多个因素。

## 🔢 核心计算公式

### 1. 基础成本计算

#### 含税总成本
```
含税总成本 = 含税单价 × 产品重量
```

#### 不含税成本（考虑退税）
```
不含税成本 = 含税总成本 × (1 - 增值税率 / (1 + 退税率))
```

**示例**：
- 含税单价：3000元/kg
- 产品重量：25kg
- 增值税率：13%
- 退税率：13%
- 含税总成本 = 3000 × 25 = 75,000元
- 不含税成本 = 75,000 × (1 - 0.13/1.13) = 66,371.68元

### 2. 利润率计算

#### 基础利润率
```
基础利润率 = 1.25% + 0.25% × (付款天数 / 30)
```

#### 最终利润率
```
最终利润率 = 基础利润率 × (1 + 付款风险系数) × 数量折扣系数
```

**付款风险系数**：
- TT（电汇）：0%
- LC（信用证）：5%
- DP（付款交单）：15%
- DA（承兑交单）：20%

**示例**：
- 付款天数：95天
- 付款条件：LC
- 基础利润率 = 1.25% + 0.25% × (95/30) = 2.04%
- 最终利润率 = 2.04% × (1 + 0.05) × 0.95 = 2.04%

### 3. 利润计算
```
利润 = 销售价格 × 利润率
```

**注意**：利润现在基于销售价格计算，而不是基于成本计算。这确保了利润率始终是售价的固定比例。

## 💰 各项费用计算

### 1. 保险费 (Insurance Premium)
```
保险费 = 销售价格 × 保险费率 × (1 + 加成率) × (1 - 特殊优惠)
```

**保险费率**：
- CIF贸易术语：0.08%
- CFR/FOB贸易术语：0%

### 2. 利息费用 (Interest)
```
利息费用 = (含税成本 + 运费 + 保险费 + 杂费) × 年利率 × 贷款天数 / 365
```

**参数**：
- 年利率：4.5%
- 贷款天数：根据付款条件调整

### 3. 杂项费用 (Miscellaneous Expenses)
```
杂项费用 = (含税成本 + 运费 + 保险费) × 0.45% + 信用成本 + 清关费
```

**信用成本**：
- LC/DA：包含单据处理费、银行费用等
- DP：180元
- TT：0元

**清关费**：
- 空运：350元
- 快递：0元

### 4. 委托费 (Commission)
```
委托费 = 销售价格 × 委托费比例
```

### 5. 总费用 (Total Expenses)
```
总费用 = 保险费 + 运费 + 利息费用 + 杂项费用
```

## 🎯 最终定价方程

### 核心方程
```
销售价格 = 不含税成本 + 利润 + 总费用 + 委托费
```

### 方程组
1. **定价方程**：`销售价格 = 不含税成本 + 利润 + 总费用 + 委托费`
2. **保险费方程**：`保险费 = get_insurance(销售价格, 贸易术语)`
3. **利息方程**：`利息 = (含税成本+运费+保险费+杂费) × 利率 × 贷款天数/365`
4. **杂费方程**：`杂费 = (含税成本+运费+保险费) × 0.45% + 信用成本 + 清关费`
5. **委托费方程**：`委托费 = 销售价格 × 委托费比例`
6. **利润方程**：`利润 = 销售价格 × 利润率`
7. **总费用方程**：`总费用 = 保险费 + 运费 + 利息 + 杂费`

## 📈 计算示例

### 输入参数
- 产品重量：25kg
- 含税单价：3000元/kg
- 付款条件：LC
- 付款天数：95天
- 委托费比例：3%
- 汇率：7.15

### 计算过程
1. **基础成本**：
   - 含税总成本：75,000元
   - 不含税成本：66,371.68元

2. **利润**：
   - 利润率：0.5%（基于售价）
   - 利润：50.12美元（基于售价计算）

3. **最终结果**：
   - 销售价格：71,672.89元
   - 委托费：2,150.19元
   - 总费用：7,247.33元
   - 美元价格：10,024美元

- **描述性命名**：避免缩写，使用完整单词
- **单位标注**：在注释中明确单位

### 代码结构规范
- **分节注释**：使用 `%% ===== 节标题 =====`
- **行内注释**：解释复杂计算逻辑
- **函数文档**：详细的输入输出说明

### 常量定义
- **利率**：`interestRate = 0.045`
- **基础利润率**：`baseProfitMargin = 0.0125`
